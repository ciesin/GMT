Help for the Geospatial Microplanning Toolkit

This help is divided into four main sections:

  1. A section with background information

  2. A tutorial section

  3. A guide to the application

  4. A section recommending standard operating procedures (SOPs)

The background section explains concepts used here and sheds some insights into some of the technical aspects behind the data used in this application.

In the tutorial section, the user can approach the application step by step and learn the different aspects of it. It is recommended to start by this section.

The guide is aimed to be utilized for reference when there are specific questions or certain functionalities need to be consulted in detail. This section also contains more details about the underlying technical aspects. The section is not complete at this point.

The SOP section recommends a general approach to perform the microplanning in this application.

If you have any questions or feedback about this application or the user guide, please do not hesitate to contact gmt@novel-t.ch.
