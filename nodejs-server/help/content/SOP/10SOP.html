1. Standard Operating Procedure for the GMT

1.1. Access and Download the Data

  1. Access the GMT on https://gmt-pilot.health

  2. Find your Ward of interest and take the data offline for the Ward(s) of interest

See section Dashboard and taking data offline

1.2. Review Health Facilities

  1. Review the health facility list and add / delete / rename / modify where necessary. See sections Health Facility deletion and addition and Adding a Health Facility with no location.

  2. Mark if needed as not performing routine immunization. See section Health facilities not performing RI.

  3. Add potentially information about health facility equipment, staff, type etc. See section Health Facility details.

1.3. Review Settlements

  1. Review the settlement list and modify / add / split / merge settlements where needed. See sections Splitting a settlement and Merging settlements.

  2. Mark settlements as uninhabited if appropriate. See section Uninhabited settlements.

  3. Add field estimated population if available as well as settlement attributes, if necessary. See section Settlement details.

  4. Rename machine generated settlements where possible. See section Settlement details.

  5. Use the guides to potentially inform about decisions whether or not to split a settlement. See sections Guides - Distance, Guides - Voronoi and Review the Settlement list / Microplanning.

1.4. Collect Missing Information

  1. Collect the data that is still outstanding in a field data collection activity. See section Field Data Collection.

  2. Enter the data in the GMT

1.5. Perform Microplanning

  1. Either using a manual procedure or the computer based algorithm, proceed to microplanning. See sections Perform Microplanning, Perform microplanning, Perform Microplanning and Perform Microplanning.

  2. Fine-tune based on local knowledge if using the computer based algorithm.

  3. Ensure all settlements are claimed, and no over-allocation exist - no errors remain.

  4. Mark the catchment status for a health facility as complete. See section Mark health facility catchment as complete.
