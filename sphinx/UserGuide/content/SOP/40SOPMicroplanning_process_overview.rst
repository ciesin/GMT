Microplanning process overview
++++++++++++++++++++++++++++++

.. Note::
    Note, this tool is designed to support microplanning. It needs to tie in with the existing microplanning processes existing. Below, the processes outside of GMT are in *italic* to make them distinct from processes within GMT.

For details on the roles and different functions described below, please refer to :doc:`/content/SOP/30SOPRoles_and_Responsibilities`. 

First time implementation
**************************

#. *Establish a steering committee*
#. *Kick off meeting with the national steering committee, involving all key actors. This should be an on-site one full day meeting to inform, plan and establish the way to implement the solution*
#. Train the GMT Program Manager
#. *Identify the high priority areas to deploy the GMT* and activate participation of those areas in GMT
#. *All staff to be involved in the activity will have to be identified and will need to be entered in the focal person registry through engagement with the relevant focal persons* and user accounts in GMT will have to be created
#. *Order the necessary equipment, if applicable SIM cards with data plans*
#. *Develop a train of trainers plan*
#. *Develop a distribution plan and accountability framework for all equipment*
#. *Source all relevant GIS data* and initialize the GMT database and, if necessary, set up a server and install the GMT on it 
#. Perform the training of people - this may need to be a regular activity during all recurrent microplanning activities

Recurring activities for each microplanning round
****************************************************

#. If GIS edits have been made outside the system (for instance boundary updates), update the database [^1]
#. Resetting of microplanning at the province level [^1]
#. Refresher exercise on GMT usage [^1]
#. *Update the focal person registry* and update the user accounts in GMT [^1]
#. Implement the microplanning on the tablet as described in :doc:`/content/SOP/50SOPMicroplanning_activity`
#. District focal person monitors microplanning progress on the dashboard and *has regular update calls with the sub-district focal persons*
#. District focal person reviews ward boundary issues and *triggers necessary discussions with neighboring wards*
#. *District focal person triggers corrective actions such as changes in outreach site placement*
#. District focal person coordinates the export, *printing and distribution of the microplan maps to all health facilities*

[^1]: This is not applicable for the first round of microplanning
