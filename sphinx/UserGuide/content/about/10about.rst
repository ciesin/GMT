About - GMT Features
+++++++++++++++++++++

On the operational level
************************

* Works offline and on tablet / PC
* Quick overview of the population within the Ward by RI strategy (fixed post, outreach, unclaimed/due for mobile health services)

Health facilities
=================

* Search, sort, addition, deletion, repositioning, renaming

* Metadata addition
	* Synonym addition
	* Services that are provided
	* Opening days for RI
	* Staff members
	* Type (primary, secondary etc)

* Outreach creation
	* Transport to get to the outreach
	* Frequency of the outreach session
	* Custom delineation of outreach catchments (default is 2km, can be outlined if needed)
	* Quick overview of population within each health facility catchment by strategy (total population, how many settlements, settlements that need special attention)
	
Settlements
===========

* Search, sort, addition, repositioning, renaming

* Metadata addition:
    * Synonym addition
    * Reason for special attention
    * Field estimated population
    * Uninhabited label / reason

* Settlement delineation / splitting / merging
* Quick overview of population that needs special attention
* Quick overview of total population per settlement
* Quick overview of settlement coverage per RI strategy (fixed post, outreach, unclaimed/due for mobile health services)

Helpers
=======

   * Settlements with field estimate / population estimate discrepancies
   * Boundary corrections


On the monitoring level
***********************

* Monitoring dashboard of microplanning (aggregated on State / LGA / Ward levels)
    * Microplan status progression: how many health facilities are currently doing microplanning   
    * Population coverage:  how much population is covered through a fixed post / outreach strategy
    * Data quality indicator: how many settlements have machine generated names

* Health facility stats:
    * Number of health facilities (doing RI or not) per State / LGA / Ward
    * What level of care for health facilities
    * Organizational level of health facilities (private / public)

* Population stats:
    * Total population per level
    * Target population per level
    * RI strategy population split (fixed post / outreach / unclaimed/due for mobile health services)
    * Number of settlements
    * Number of settlements that need special attention

* Data quality stats:
    * Settlements that need special attention
    * Missing base data per level
    * Number of boundary corrections
    * Number of population discrepancies

* Register individual States / LGAs / Wards which will make use of the GMT to support / produce their geospatial microplan 
* Exporting of data:
    * Batch export for multiple boundaries at once possible
    * PDF export of microplanning map (one map per Ward and optionally per health facility)
    * Excel export of the microplan 
    * Export of a GDB
