What is GMT for ?

The Geospatial Microplanning Toolkit (GMT) facilitates the creation of digital microplans in a user friendly way, allowing both attributive and geospatial delineation of catchment areas.

At its core is geospatial settlement and health facility data. Health facility and settlement details can easily be modified. In cases where information is incomplete, data collected from the field - for instance using the GTS or ODK forms - can be drag-and-dropped into the application, which automatically updates the dataset. Depending on the user profile, microplans can be edited, surveyed or visualized. For certain user groups, a dashboard summarizes microplan creation progress as well as data completeness. Various types of exports are available for the different users to aid decision making.

All interactions with the microplan and modifications to settlements and health facilities can be performed offline. The application runs in in a standard web browser and no additional software is required. It is intuitive to use and requires little training.
